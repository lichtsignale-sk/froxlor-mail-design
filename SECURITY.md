# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub's security advisories: on the
repository page, open **Security › Advisories › Report a vulnerability**
(see GitHub's documentation on "Privately reporting a security
vulnerability"). Include the affected version, the Froxlor and PHP versions,
and steps to reproduce.

You will get an answer as soon as possible; once a fix is available, the
advisory is published together with the release.

## Supported versions

Only the latest release receives security fixes.

## Scope

This extension runs a local SMTP relay (127.0.0.1) and accepts a logo upload
in the Froxlor admin panel. Issues in Froxlor itself should be reported to the
Froxlor project.
